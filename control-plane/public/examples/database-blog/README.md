# 작은 기록 — 나루 데이터베이스 예제

글 목록, 글 상세, 공개 생성 전용 방명록, 관리자 글쓰기를 갖춘 정적 웹사이트입니다.
SDK 1.0.0을 사용합니다. 빌드나 패키지 설치가 필요 없습니다.
한국어 안내: https://naru.pub/database/docs/

## 설치

1. https://naru.pub/database 에 로그인하세요.
2. posts 컬렉션: 읽기 공개(world), 쓰기 관리자(admin).
3. guestbook 컬렉션: 읽기 공개(world), 쓰기 공개 생성만(create).
4. 예제를 업로드할 위치를 정하세요. 기존 홈페이지를 보존하려면 blog 폴더를 사용하세요.
5. 제어판의 '웹사이트 관리자 로그인'에 정확한 콜백 URL을 등록하고 posts만 선택하세요.
   루트: https://내사이트.naru.pub/admin.html
   blog 폴더: https://내사이트.naru.pub/blog/admin.html
   본인의 활성화된 인증 도메인도 가능합니다. 쿼리와 #은 넣지 마세요.
6. config.js의 site에 나루 로그인 이름, clientId에 등록한 Client ID를 넣으세요.
   Client ID는 비밀이 아닙니다. 비밀번호나 토큰을 코드에 넣지 마세요.
7. 모든 파일을 같은 폴더에 업로드하고 호스팅된 index.html을 여세요.
   file://로 직접 열지 마세요.

## 확인

- 글쓰기에서 나루로 관리자 로그인 → 승인 → 글 공개하기.
- 공개된 글을 글 목록과 상세 페이지에서 확인하세요.
- 관리자 권한을 해제하고 방명록에 인사를 남겨 보세요.
- 방명록 방문자는 추가만 가능합니다. 삭제/수정은 제어판에서 합니다.
- 로그인하지 않은 사람이 글을 쓰려고 해도 서버가 거부해야 합니다.
- 공개 add는 응답 유실 시 중복 생성될 수 있습니다. 목록을 확인한 뒤 재시도하세요.

## 파일

- config.js: 사이트와 Client ID 설정
- client.js: SDK 1.0.0 연결
- index.html / list.js: 글 목록 (방명록 목록과 스크립트 공유)
- post.html / post.js: 글 상세
- guestbook.html: 인사 작성 및 목록
- admin.html / admin.js: 소유자 승인과 글 공개
- utils.js / style.css: 안전한 텍스트 렌더링, 공통 UI

## 동작과 보안

문서는 ID 순서입니다. 최신순 정렬, 실시간 갱신, Markdown은 구현하지 않습니다.
HTML 문자열을 실행하지 않으며 방문자 입력은 textContent로 표시합니다.
프런트엔드 입력 길이 제한은 서버 검증을 대신하지 않습니다.
방명록 이름은 인증되지 않습니다. 스팸은 소유자가 제어판에서 관리하세요.

관리자 토큰은 메모리에만 남고 10분 후 만료됩니다. 새로고침하면 다시 승인받으세요.
초안은 로그인 이동을 위해 같은 탭의 sessionStorage에 저장합니다. 토큰은 저장하지 않습니다.
공용 기기에서는 탭을 닫으세요. 페이지에 신뢰할 수 없는 외부 스크립트를 추가하지 마세요.
초안별 고정 ID로 set을 호출해 네트워크 재시도로 인한 중복 글을 방지합니다.
공개된 글 수정/삭제는 제어판을 사용하세요. posts에 비공개 초안을 저장하지 마세요.

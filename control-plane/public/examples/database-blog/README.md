# 작은 기록 — 나루 데이터베이스 예제

분류별 글 목록, 글 상세, 방명록, 관리자 편집·삭제와 비공개 초안을 갖춘 정적 웹사이트입니다.
SDK 1.0.0을 사용합니다. 빌드나 패키지 설치가 필요 없습니다.
한국어 안내: https://naru.pub/database/docs/

## 설치

1. https://naru.pub/database 에 로그인하세요.
2. 다음 컬렉션을 만드세요.
   - posts: 읽기 공개(world), 쓰기 관리자(admin)
   - guestbook: 읽기 공개(world), 쓰기 공개 생성만(create)
   - drafts: 읽기 관리자(admin), 쓰기 관리자(admin) — 반드시 비공개로 설정하세요.
3. 업로드할 위치를 정하세요. 기존 홈페이지를 보존하려면 blog 폴더를 사용하세요.
4. '웹사이트 관리자 로그인'에 정확한 콜백 URL을 등록하고 posts와 drafts를 선택하세요.
   루트: https://내사이트.naru.pub/admin.html
   blog 폴더: https://내사이트.naru.pub/blog/admin.html
   본인의 활성화된 인증 도메인도 가능합니다. 쿼리와 #은 넣지 마세요.
5. config.js의 site에 나루 로그인 이름, clientId에 Client ID를 넣으세요.
   Client ID는 비밀이 아닙니다. 비밀번호나 토큰을 코드에 넣지 마세요.
6. 모든 파일을 같은 폴더에 업로드하고 호스팅된 index.html을 여세요. file://로 열지 마세요.

기존 예제 업그레이드: drafts를 추가한 뒤 기존 웹사이트 등록을 삭제하고 posts와 drafts를 선택해 다시 등록하세요.
등록의 범위는 수정할 수 없습니다. 새 Client ID로 config.js를 갱신하세요. 이전 토큰은 폐기됩니다.

## 글 관리

- 글쓰기 → 나루로 관리자 로그인 → 승인.
- 제목과 본문, 선택적으로 분류(예: 일상)를 입력하세요.
- '비공개 초안 저장'은 drafts에 저장합니다. 같은 ID의 기존 공개 글은 그대로 유지됩니다.
- '글 공개하기'는 posts에 먼저 저장한 뒤 해당 drafts 문서를 삭제합니다.
- '목록 불러오기'에서 공개 글 / 비공개 초안을 선택하고 제목을 눌러 편집하세요.
- '공개 글 저장'은 선택한 글을 수정합니다. '새 글 작성'을 눌러야 별도 글이 만들어집니다.
- 삭제는 확인 후 선택한 컬렉션의 문서만 영구 삭제합니다. 같은 ID의 다른 컬렉션 문서는 유지됩니다.
- 방명록 수정/삭제와 권한 설정은 제어판에서 합니다.

공개 저장과 초안 삭제는 하나의 트랜잭션이 아닙니다. 공개가 실패하면 초안은 남습니다.
공개 후 초안 정리가 실패하면 안내가 표시됩니다. 같은 글을 다시 저장하거나 초안 목록에서 삭제하세요.
초안별 고정 ID를 사용하므로 공개 저장 재시도는 중복 글을 만들지 않습니다.
여러 탭에서 동시에 편집하지 마세요. 서버는 마지막 저장을 우선하며 충돌 감지는 하지 않습니다.

## 필터와 페이지 이동

글과 방명록은 서버 생성 시각(created_at) 내림차순, 관리자 목록은 수정 시각(updated_at) 내림차순입니다.
같은 시각이면 ID 내림차순입니다. 공개 목록의 분류 필터는 `where: { category: "일상" }`로 정확히 비교합니다.
더 보기에는 같은 where/orderBy/direction과 응답의 nextCursor를 after로 보냅니다.
분류를 바꾸면 목록과 커서를 초기화합니다. 빈 분류는 전체 목록입니다.
JSON 필터와 시각 정렬 인덱스는 나루가 자동으로 관리합니다.
created_at은 서버가 정하며 수정해도 유지됩니다. 기존 문서는 마이그레이션 당시 updated_at으로 채워집니다.

## 확인

- 비공개 초안을 저장한 뒤 공개 목록에 나타나지 않는지 확인하세요.
- 초안을 공개하고 분류 필터, 글 상세, 수정, 삭제를 확인하세요.
- 로그인하지 않은 방문자는 drafts를 읽거나 posts를 변경할 수 없어야 합니다.
- 방명록 방문자는 추가만 할 수 있습니다. 응답 유실 시 이미 저장되었을 수 있으니 목록을 확인한 후 재시도하세요.

## 파일과 보안

- config.js / client.js: 사이트 설정과 SDK 1.0.0 연결
- index.html / list.js: 분류별 목록 및 방명록
- post.html / post.js: 글 상세
- guestbook.html: 인사 작성 및 목록
- admin.html / admin.js / editor.js: 소유자 승인, 편집, 초안, 공개, 삭제
- utils.js / style.css: 안전한 텍스트 표시와 공통 UI

HTML은 실행하지 않고 textContent로 표시합니다. 실시간 갱신, Markdown은 구현하지 않습니다.
입력 길이 제한은 서버 검증을 대신하지 않습니다. 방명록 이름은 인증되지 않습니다.
필터는 접근 권한이 아닙니다. posts에 비공개 초안을 저장하지 마세요.
관리자 토큰은 메모리에만 남고 10분 후 만료됩니다. 새로고침하면 다시 승인받으세요.
작성 중인 글은 로그인 이동을 위해 같은 탭의 sessionStorage에 저장합니다. 토큰은 저장하지 않습니다.
서버 초안은 '비공개 초안 저장'을 눌러야 보관됩니다. 공용 기기에서는 권한을 해제하고 탭을 닫으세요.
신뢰할 수 없는 외부 스크립트를 추가하지 마세요.
